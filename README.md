Spam Mail Prediction Using Machine Learning

📌 Project Overview

This project uses Machine Learning to classify messages as Spam or Ham (Not Spam) using Logistic Regression. It applies Natural Language Processing (NLP) techniques and TF-IDF vectorization to convert text messages into numerical features that a machine learning model can understand.

The goal is to identify unwanted or spam messages and distinguish them from legitimate messages.

🎯 Objectives

Classify messages as spam or legitimate.
Preprocess text data for machine learning.
Convert text into numerical features using TF-IDF.
Train a Logistic Regression classification model.
Evaluate the model's performance on test data.

🛠️ Technologies Used

Python
Google Colab / Jupyter Notebook
Pandas — data manipulation
NumPy — numerical operations
Scikit-learn — machine learning and feature extraction
TF-IDF Vectorizer — text feature extraction
Logistic Regression — classification algorithm
